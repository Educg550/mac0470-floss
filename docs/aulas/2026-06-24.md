# Aula 24/06/2026

Fomos à aula referente a sugestões de projetos para contribuição para a próxima etapa da disciplina.
O interesse da minha dupla é o [cregit](https://github.com/cregit-codev/cregit), ferramenta de
tokenização de linhas de código como forma de alternativa mais granular ao git blame.

Já eu criei mais interesse pela contribuição do ambiente [KDE](https://kde.org/),
pois desde tempo já utilizo diversas ferramentas do KDE, como o KDE Neon, Okular,
Plasma, e outras. Acredito que uma contribuição razoável para o ecossistema
que eu mesmo já aproveitei diversas vezes é muito interessante.
