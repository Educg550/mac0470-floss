# Aula 04/03/2025

**Tutorial:** [Build Linux for ARM with kw](https://flusp.ime.usp.br/kernel/build-linux-for-arm-kw/)

Compilação cruzada do kernel Linux para ARM64 com `kw` (kworkflow): clone do repositório IIO, configuração via `defconfig`/`localmodconfig`, build e deploy dos módulos na VM.

## Observações

- Dificuldade para iniciar a VM com `virsh`/QEMU.
- Dificuldade na interface de configuração (`menuconfig`).
- Demais etapas concluídas sem problemas.
