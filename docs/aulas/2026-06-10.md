## Sobre o driver `adf4377.c`

O `adf4377.c` é o driver Linux do **ADF4377**, um sintetizador de frequência da Analog Devices, no subsistema IIO. 
O driver fala com o chip via `regmap` e o `mutex` que estamos protegendo serializa esse acesso aos registradores.

## Resumo das mudanças

A ideia do patch é deixar o compilador liberar o `mutex` em todo caminho de saída, eliminando o padrão manual e os `goto exit`:

```c
/* antes */
mutex_lock(&st->lock);
ret = regmap_read(st->regmap, 0x12, &ref_div_factor);
if (ret)
	goto exit;

/* ... */

exit:
	mutex_unlock(&st->lock);
	return ret;

/* depois */
guard(mutex)(&st->lock);

ret = regmap_read(st->regmap, 0x12, &ref_div_factor);
if (ret)
	return ret;

/* ... */

return 0;
```
