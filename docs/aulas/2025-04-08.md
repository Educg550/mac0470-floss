# Aula 08/04/2025

**Tutorial:** [Sugestões de patches para a árvore do kernel](https://flusp.ime.usp.br/courses/linux-kernel-patch-suggestions/)

## Atividade

Aula sobre como identificar e propor patches para o kernel Linux. Decidimos trabalhar no patch de substituição de `mutex_lock` por `guard(mutex)` no subsistema IIO.

Durante a aula, implementamos o patch no arquivo `drivers/iio/frequency/adf4377.c` e fizemos o commit na branch local.
