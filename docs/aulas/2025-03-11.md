# Aula 11/03/2026

**Tutorial:** [Introdução a módulos do kernel](https://flusp.ime.usp.br/kernel/modules-intro/)

Escrita de módulo mínimo em C, integração ao sistema de build (Kconfig + Makefile), compilação, deploy na VM e carregamento dinâmico com `insmod`/`rmmod`. Exportação de símbolos entre módulos com `EXPORT_SYMBOL_NS_GPL`.

## Observações

- Uma variável de ambiente necessária pelo tutorial não existia no ambiente.
- `kw build` falhou porque o tutorial não incluía a declaração de `description` no módulo — erro de compilação.
- Após deploy, dificuldade com `kw ssh` devido à mudança de IP da VM.
- No geral, primeiros módulos criados com sucesso.
